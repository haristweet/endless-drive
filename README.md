# ENDLESS DRIVE

車で延々と走り続けるのを眺めるアプリ。そのまま MP4 に書き出せる。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/)・[ENDLESS FLIGHT](https://haristweet.github.io/endless-flight/)・[ENDLESS WALK](https://haristweet.github.io/endless-walk/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 道7種を順に巡る（選んだものだけ。2分ごとなどで暗転して「2つ目の道」と出る）
  - 首都高の夜景：高架の道、オレンジの照明、緑の案内標識、下に広がるビル街（窓の灯り・屋上の赤い灯り）
  - 海沿いの道：ガードレールの向こうに海、山側は草の斜面と家、船、ときどき灯台
  - 山の峠道：大きく曲がって上り下りする道、擁壁と針葉樹、谷側のガードレール、急なカーブの矢印板
  - 長いトンネル：アーチの天井、オレンジの灯りの列、非常口の緑の灯り（中は時刻に関係なく灯りで照らす）
  - 田園の道：田んぼ、電柱と電線、農家と木立、遠くの山
  - 雪の国道：雪の路面とわだち、雪の壁、矢羽根（道の端を示す赤白の柱と矢印）、雪をかぶった針葉樹、降る雪
  - 夕陽の海岸線：80年代ふうの夕暮れ（時刻は夕方のまま）、赤白の縁石、ヤシ並木、紫の山
- 対向車（乗用車とトラック）が来る。夜はライトが光る
- 時刻がゆっくり移り変わる（朝→昼→夕方→夜）。暗くなると自分の車のヘッドライトが前の道を照らす
  - 一日の長さ：4分 / 8分 / 16分、走り始める時刻：朝・昼・夕方・夜
- 描き方：ポリゴン / 線画、視点：運転席（右ハンドル。ダッシュボードとハンドルが見える）/ 運転席（ダッシュボードなし。同じ目の高さから前だけ）/ 後ろから / ボンネット
- 画面の飾り（あり：速度計と回転計・地図・ラジオ欄〈歌詞もここに流す〉）
- 画素の粗さ、速さ（50 / 80 / 120 km/h）、道の番号（シード。同じ番号なら同じ道のり）
- MP4書き出し：640×480〜1920×1080、「3:19」のような長さ指定、30 / 60コマ/秒、音と歌詞（ラジオ欄か字幕に流す）
- 終わり方：曲を入れて「BAD END にする」にチェックを入れると、終わりの数秒前に対向車がはみ出してきて（首都高では白い逆走車が自分の車線を来て）、曲が終わるところで正面衝突する。フロントガラスが割れ、赤く染まって暗転し「BAD END／ドライブは ここで 終わった」

## しくみのメモ

- **道**：正弦波の和で左右にゆるく曲がり、上り下りする道（峠は大きく、首都高は高さ12mの高架）。長さ30mごとの区切りを、番号・道・区切りの番号から決まる乱数でその場で組み立てる。左側通行で、自分の車線は道ごとの `lane`、対向車線は `onc`。
- **横断面**：道の中心からの横の位置と高さの2点を結ぶ帯（`prof`）を道に沿って並べて、路面・壁・斜面・トンネルのアーチを作る。
- **対向車**：遠く（見通しの端）に出て、こちらへ走ってくる。うしろへ過ぎたら消す。道が変わると入れ替える。
- **時刻**：ENDLESS WALK と同じ表を使う。トンネルの中は空の代わりに灯りの色で照らす。夕陽の海岸線は時刻を夕方に固定。
- **ヘッドライト**：描画のときに、車の前の円すいの中を遠くほど弱く明るくする（暗さに合わせて強く）。
- **バッドエンド**：`CRASH`（見える秒・ぶつかる秒・相手の速さ）と `Sim.crash()`。相手は 1.2 秒かけて対向車線からこちらの車線へはみ出す。ぶつかったら両方止まって回る。運転席・ボンネットでは前へつんのめって傾き、フロントガラスが割れる（`drawCracks`）。音（クラクション・急ブレーキ・ぶつかる音・ガラス）は ENDLESS WALK と同じものを曲の上に重ねる。終わりの8秒前より後には道を変えない。
- **描画**：ENDLESS WALK・FLIGHT と同じ WebGL2 の仕組み（重心座標で辺を線にする・線画は面を黒く塗って隠れ線処理）。
- **書き出し・音・歌詞**：ENDLESS DUNGEON / FLIGHT / WALK と同じ。
- ローカル確認：`python3 -m http.server 8802`
- 時刻のひとことの試験：`node test/msgs.mjs`（0 秒のコマでまとめて出ないこと・一日で順に一度ずつ出ること）
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（道ごとに運転席の昼と後ろからの夜を並べる）。BAD END を見るときは `TIMES=14,16.3,17.2,17.55,18,18.8,19.6 ROWS='[["highway","driver","solid",false,"evening",true]]'` のように時刻と［道・視点・描き方・飾り・走り始め・BAD END］を渡す
